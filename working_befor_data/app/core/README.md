# Core Directory

This directory contains the core business logic and optimization components.

## Components

- `optimizer.py`: Implements the optimization logic for routing decisions
  - Handles SLA calculations
  - Processes routing rules
  - Applies optimization algorithms for route selection

## Purpose

The core module is responsible for the central business logic that powers the routing system. It takes the data from various sources and applies optimization algorithms to determine the most efficient routing paths while considering SLA requirements.
