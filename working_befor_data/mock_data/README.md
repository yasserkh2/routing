# Mock Data Directory

This directory contains mock data files used for development and testing.

## Files

- `links_data.json`: Mock data for network links and their properties
- `price_changes.json`: Sample price change events and updates
- `profiles.json`: Mock routing profiles and configurations

## Purpose

The mock data directory provides:
- Consistent test data for development
- Sample data structures for reference
- Offline development capability
- Test scenarios and use cases

## Usage

These mock data files are used by:
- Unit tests
- Integration tests
- Development environment
- Mock services
- Example implementations

The data structure in these files mirrors the expected production data format, ensuring smooth transition from development to production environments.
